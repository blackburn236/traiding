TRADING ANALYZER V19.1 — WEBSITE

NOVIDADES
- Seletor de ativos redesenhado com cores por ativo, ícone/ponto luminoso e menu escuro.
- Mais ativos: BTC, ETH, BNB, SOL, XRP, ZEC, ADA, DOGE, AVAX, LINK, DOT, TRX, LTC, BCH, NEAR, APT, SUI, UNI, PEPE e SHIB.
- Mantém 1m / 5m / 15m, gráfico em tempo real, SINAL ATUAL, PRÓXIMA VELA, SMA6, EMA5, RSI, Volume, ATR, VPG, suporte, resistência e Order Block.

TESTE NO WINDOWS
1) Abra um terminal na pasta do site.
2) Execute: python -m http.server 8000
3) Abra no PC: http://localhost:8000

ALTERNATIVA
Execute run_site.bat.

TELEMÓVEL
Para usar no telemóvel com dados em tempo real, publique esta pasta num servidor HTTPS. Depois abra o endereço no navegador; o site foi preparado para ecrã pequeno e instalação como aplicação web (PWA).

DADOS
Usa dados públicos da Binance e não envia ordens. A integração real com a API da Assett Broker ainda não está verificada.

SINAIS
“ENTRADA AGORA”/“SINAL ATUAL” = estado técnico da vela atual. “PRÓXIMA VELA” = previsão técnica da vela seguinte. Nenhum sinal garante resultado.
